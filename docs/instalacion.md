# Instalación

## Requisitos

- Git
- Python 3

## Pasos

1. Clona el repositorio:

```bash
    git clone git@github.com:adamessadaoui03-arch/prueba_Adam.git
    cd prueba_Adam
```

2. Instala MkDocs y el tema Material:

```bash
    python -m pip install mkdocs mkdocs-material
```

3. Comprueba la instalación:

```bash
    mkdocs --version
```

*Nota:* según tu sistema, el comando de Python puede ser `python` o `python3`.
