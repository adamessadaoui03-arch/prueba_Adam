# Uso

## Ver la documentación en local

```bash
mkdocs serve
```

Abre `http://127.0.0.1:8000` en el navegador.

## Comandos principales

| Comando | Qué hace |
|---------|----------|
| `mkdocs serve` | Servidor local de desarrollo |
| `mkdocs build` | Genera el sitio estático en `site/` |
| `mkdocs gh-deploy` | Publica en GitHub Pages |
